# 🤖 Hacker Scripts Extra **Cuando el micromanagement corporativo exige automatización al límite del absurdo.**  
--- > `xxx`: El director de ingeniería exige que todos escribamos un reporte detallado en Slack todas las mañanas a las 9:00 sobre *"qué hicimos ayer y qué haremos hoy"*. Si no escribes nada, asumen que estás jugando videojuegos. > > `xxx`: Así que estuve mirando el repositorio del turno de noche... y encontré esto. Inspirado en el legendario repositorio hacker-scripts, este conjunto de herramientas automatiza la burocracia corporativa más tóxica para que tú puedas concentrarte en lo importante (o simplemente dormir 10 minutos más). --- ## 📂 El Arsenal * **`not-another-standup.py`** — Lee tus commits reales del día anterior mediante `git log`, los pasa por un filtro algorítmico de lenguaje corporativo agilista (*"optimizando la sinergia de microservicios"*) y los publica automáticamente en Slack a las 8:55 AM. Si no programaste nada, selecciona aleatoriamente una excusa de arquitectura cloud de alto nivel. * **`auto-git-excuse.py`** — ¿Terminó el día y no tienes nada que mostrar? Este script genera un commit técnico automatizado con mensajes sumamente complejos y profesionales (*"refactor: optimización de punteros de memoria y limpieza de descriptores de archivos huérfanos"*), modificando un archivo de log local y haciendo push de respaldo a la red. --- ## ⚙️ Configuración y Uso ### 1. Clonar el repositorio ```bash git clone https://github.com/Daedalus-DevM240/hacker-scriptsextra.git cd hacker-scriptsextra ``` ### 2. Configurar las variables de entorno Crea un archivo `.env` en la raíz del proyecto para definir tu Webhook de Slack: ```env STANDUP_WEBHOOK_URL=https://hooks.slack.com/services/TU/WEBHOOK/REAL ``` ### 3. Automatizar con Cron (Modo "Invisible") Abre tu editor de crontab con `crontab -e` y añade los trabajos programados para que corran solos de lunes a viernes: ```sh # Envía el standup falso corporativo a las 8:55 AM 55 8 * * 1-5 /usr/bin/python3 /ruta/a/hacker-scriptsextra/not-another-standup.py >> /ruta/a/standup.log 2>&1 # Ejecuta el commit de respaldo automático a las 6:00 PM 0 18 * * 1-5 cd /ruta/a/hacker-scriptsextra/ && /usr/bin/python3 auto-git-excuse.py && git push origin main >> /ruta/a/git-excuse.log 2>&1 ``` --- ## 🤝 Contribuciones ¿Tienes una idea aún más absurda para esquivar reuniones inútiles, simular actividad en Jira o responder correos pasivo-agresivos de clientes? ¡Los *Pull Requests* con más automatizaciones cínicas son totalmente bienvenidos!
